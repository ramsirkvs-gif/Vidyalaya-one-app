# Principal survey exports

In **Principal login → Task Manager**, save edits, then choose **Prepare presentation report**. The preview reads the latest saved records. It does not publish survey answers.

The main presentation contains pie charts for selected numeric questions in Part I (Class IX) and Part II (Classes IX–XII), followed by **Report overview** after the last chart. Written-answer placeholder cards and question-number prefixes are omitted. The overview shows submitted classes covered, their supplied enrolment, distinct observer teachers/prime mentors, and how many observers provided remarks. Missing enrolment is identified, not invented. Participant names appear in small print. The main presentation is at most four A4 landscape pages.

**Select presentation questions** controls only export content. Survey numbering remains in the selector, forms and class-wise reports. Up to 24 selected points are supported. Text responses go into the comments annexure rather than the chart grid.

Q7 and Q8 are merged when both selected questions count students. The Principal confirmed that these groups do not overlap. Only classes with both compatible answers are summed; the matched enrolment is counted once. An impossible combined count exceeding enrolment is flagged instead of displaying an invalid percentage. The separate survey answers are retained. Q6 includes **(either one or both parents are uneducated)** as a display clarification, without invalidating existing responses or submission status.

# PDF, PowerPoint and annexures

**PDF options** and **PPTX options** each provide independent choices for class-wise reports, teacher comments, and closing remarks. Every option is off by default. The preview follows the PDF choices; **Download PPTX** follows only the PPTX choices. Charts and the final overview are always included in the main presentation. Selected attachments follow in class-wise, teacher-comment, closing-remark order. The main chart report remains at most four pages; attachments may add pages/slides.

If either format includes class-wise reports, open **Select classes for annexure** and check the submitted classes to include. This shared class selection applies to both formats. The existing class-wise table layout and numbering are retained. Comments and closing remarks are independent: selecting one does not automatically select the other. Enabling closing remarks reveals individual RO, DC, AC, Principal-action and higher-official choices separately for PDF and PPTX. Saved notes are selected initially within that group; blank notes are disabled. You may omit any saved note without deleting it. Empty comment sections are skipped.

**Print / Save PDF** prints the preview using A4 landscape. Disable browser-added headers/footers. **Download PPTX** creates a real PowerPoint file with editable text and native pie charts. PptxGenJS and its licence are bundled locally; export content is not sent to an external service.

**Class-wise survey PDF** and **Comments annexure PDF** open separate annexure previews, each with PDF and PPTX export available. Full class reports retain Q1–Q3 figures, all submitted answers, written responses, overall comments and retained earlier answers. These complete reports are independent of presentation-question selection.

# Whole-report comments and corrections

Below the results, open **Closing comments for the whole report**. Save separate notes for RO efforts, Deputy Commissioner guidance, Assistant Commissioner guidance, Principal action, and higher KVS officials' visits/guidance. They are private to the Principal and exported with the comments annexure or optional PDF appendix.

Submitted classes show green **✓ Submitted**; pending classes show **Pending** in red. Choose **Open report → Edit submitted answers → Save submitted answers** for Principal corrections without a teacher PIN. Q1–Q3 remain read-only. Corrections preserve teacher attribution and original submitted question wording, retain a private history, update totals, and reject stale saves. Public and teacher PIN permissions remain unchanged.

Known grammatical errors are corrected for display and in the shared editor without changing meaning. Stored report snapshots retain original wording; grammar-equivalent edits preserve earlier compatible counts. Substantive changes still require teacher confirmation.

Student percentages use classes with both compatible counts and supplied enrolment. PTMs show meeting distributions. Blank answers are excluded; confirmed zero remains zero. Categories other than the explicitly merged pair may overlap. Reported circumstances are associations, not proof of causation. Preview selections and additional co-opted participant names are not saved to the task; closing the preview or ending the Principal session clears the preview.
