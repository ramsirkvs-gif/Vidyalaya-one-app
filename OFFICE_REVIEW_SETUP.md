# Office submissions and Principal review

Office members submit Part A and Part B with their existing office PIN. A green success receipt appears only after the server confirms the saved record. Changes to another voucher no longer block submission. If the same voucher changed, use **Refresh latest record — keep my entries**, review the displayed changes, and submit again.

Open **Principal review & replies** on the office dashboard. Filter by **Open objections**, **Awaiting review / final status**, or **No objection / Done**. Office members use **Respond to objection** and their existing office PIN to send a private reply. The Principal sees the response in the same section and can use **Review / edit objection and final status**. To close the review, choose **No objection / Done**, then **Save office record**. Replies do not change the Principal's final status and are excluded from published staff views.

# Task submission status

In Principal Task Manager, published tasks show **Submission status and results** above the editor. **View submission status** jumps there. The section shows submitted and pending totals, teacher assignments, and each class's status. Choose **Open report** for a submitted class to read its answers.

# Immediate voucher search

Typing in the register's search box shows the first five matches immediately beneath it, with voucher details and an **Open voucher** action for authorized editors. Searches still match exact voucher numbers. If an existing match is hidden by filters, the result explains this and offers **Clear filters and show voucher**. If the current register has no match, it identifies that scope and offers **Search all accessible registers**, using the existing access permissions. No edits or publication are performed by searching.
