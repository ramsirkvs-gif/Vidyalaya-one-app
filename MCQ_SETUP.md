# MCQs महाअभियान — shared Class X and Class XII banks

Open staff view or sign in as Principal, then choose **MCQs महाअभियान → Class X / Class XII**. Principal workspace headers, the Mission home and Principal controls all provide direct MCQ shortcuts. Change class returns to the entrance. Banks, subject lists, paper selections and evaluation rosters stay within the chosen class. Existing records without a class field remain Class X; no migration or renumbering is required.

1. **Contribute 10 / 20 MCQs:** the prominent coloured button opens a contribution. The authenticated Principal contributes as Principal using their existing protected session; no teacher PIN or teacher identity is required. Staff contributors still verify their personal PIN. The name list contains active subject teachers of the chosen class, including saved cross-class teaching allocations. A single saved subject allocation is inferred. Select a saved topic, Mixed or Add new topic. Paste ready numbered questions with A), B), C), D) options into the large notepad; alternatively upload one complete question photo per question, including all four options. Multiple photos can be selected together. Tap one A/B/C/D radio button per question in the answer strip; there is no typed answer key. Process, review the previews and submit with the contributor’s PIN. A verification popup asks for confirmation before saving; no declaration checkbox is required. Contributor details use a compact grid and the PIN sits beside submission. To change pasted questions, replace the prepared text and process again. No mathematical editor is required. Direct-photo mode needs no OCR correction; extraction mode requires reviewing and correcting the recognised text.
2. **Create QP:** another eligible teacher can reuse any contribution in the selected class, or combine 10/20 questions from multiple batches of one subject. The searchable list shows permanent question IDs and topics, with checkboxes. Topic/question/ID searches cover the full saved bank, including later pages. Selections persist across searches and pages; changing subject clears them. Choose a target of 10 or 20, watch the sticky selection count and press Generate paper when the exact target is reached. Further unchecked boxes are disabled at the target. Nothing is removed/reserved. A paper freezes order/content/key. Print/save the A4 paper without an answer key using the browser print dialog. Whole-question photos print directly without duplicate placeholder options. The shared **Ready-to-print papers** library shows each paper’s permanent ID, prepared-by name, subject, frozen topics and question count. Search by creator, subject, topic or ID, preview/print and reuse the same paper for another section. Newly generated papers appear immediately. This does not duplicate or alter the paper or key. The QR payload contains only `VOA|MCQ|<paper ID>`. A standardized bubble response strip is included.
3. **Evaluation:** select/scan the test ID, section and an enrolled student. Class X uses A–D; Class XII uses saved sections, including E. Enter responses manually or photograph/crop the printed response strip including all four black corner squares. Review every response and selected student, then submit with the evaluator’s PIN (or the authenticated Principal session). Grading uses the server’s frozen key and saves the result atomically with an academic exam/mark. Duplicate results are rejected. Corrections require Principal authentication; staff-attributed corrections also require the evaluator PIN. A private previous-result audit is retained.

Class X IDs retain `M10-`, `B10-` and `QP10-`; Class XII uses independent `M12-`, `B12-` and `QP12-` counters. Save-request IDs prevent duplicate contributions/papers on retry. Questions are immutable; revised contributions receive new IDs.

The manifest is `cbse-mcq-syllabus.js`, session **2026–27**. Direct official-host verification is still pending: the environment proxy denied access to CBSE, SelfStudys and Careers360. Reviewed public PDF copies were found in [usp1904/cbse-app](https://github.com/usp1904/cbse-app/tree/e1f9905ae09eec154d492e60ed949ac3eb6ba08b/Syllabus_2026-27/CBSE), and their internal headings identify 2026–27. Each source entry pins the public-copy URL to an exact commit, records its SHA-256 and review date, and retains the official URL reported by the source repository. No PDF or external program is bundled/executed. `verified: false` explicitly means these copies have not been compared against the live official host. Other subjects retain Mixed, saved subject topics and Add new topic until their current-session documents are reviewed. Existing bank topics/questions are untouched. This is partial subject coverage; do not describe the catalog as covering every CBSE subject.

## Photos: direct image or extract text

The Source dropdown has three choices: Paste ready MCQs, **Use photo directly**, and **Extract text from photo**.

- **Use photo directly:** upload one complete question image per question. Its text, options and diagram remain an image in the paper.
- **Extract text from photo:** choose English, Hindi or English + Hindi, take/upload a book photo, crop its question text/options and press Extract text into notepad. Recognition uses bundled Tesseract.js models in the browser; the photo is not sent to an external OCR service. Existing prepared text is preserved and recognised questions append with fresh numbering. Review/correct the notepad, especially option labels, equations, Hindi characters and small symbols. Then Process & arrange. No answers are inferred or selected automatically, and extraction never submits anything. A cancelled crop or failed extraction retains the existing notepad and permits retry.
- For a question containing both text and a diagram, use **Crop diagram from last photo** on its arranged preview to attach a cropped image from the last successfully recognised source photo. This is a manual crop, not automatic diagram extraction/redrawing. Photos from older pages can still be attached with the existing Add question diagram upload. The contributor checks the correct diagram is attached to each question.

All routes use the same touch A/B/C/D answer strip, review/submit confirmation and protected Principal session or staff PIN. OCR is loaded only when requested; direct-photo contributions do not use it. The original book photo and unsaved OCR text stay in browser memory; only the explicitly submitted text and chosen diagram crops are saved privately.

Upload complete ready questions, with optional replacement/cropping during review; diagrams may also be attached to pasted text questions. Never include marked solutions or visible correct-answer marks. Direct photos are cropped/resized while preserving their aspect ratio; maps/diagrams are not automatically redrawn, interpreted or checked for correct map/diagram labels or mathematical symbols. Contributors must review legibility, especially small labels, at A4 print size. A failed image load stops printing rather than silently omitting it. Rasterization drops camera metadata. Photos and answer keys stay private. Photo-assisted bubble reading supports the generated response strip with perspective alignment from its four black squares. Retake blurred/obscured photos or enter responses manually. Scans require review and never auto-submit; arbitrary handwriting is not automatically graded.

## Storage and access

Private questions, frozen paper keys, evaluations, evidence and correction audits live under `cbse/mcq`, outside `cbse/mission` and public snapshots. Existing rules deny client access at this path; the server service checks protected staff browsing or Principal access and verifies PIN writes. Browse responses omit keys, PINs, evaluation photos and audits. Builds include only code and third-party QR assets. Ordinary Mission backups include integrated marks but not this separate bank; authorized administrators must include `cbse/mcq` in private database backups.

Bank reads paginate 20 questions. The ready-paper library searches all saved papers and paginates 20 at a time, independently of the question-bank filters. Older papers also remain loadable by permanent test number. Legacy paper topic lists are derived from their frozen question snapshots without rewriting any records.

## Build and validation

Use Node 22, `npm ci`, `npm run build`. Locked QR/OCR dependencies and English/Hindi language data are copied to ignored `vendor/mcq/` and generated public assets with licenses; no external OCR service is used.

Run `node --test tests/*.test.mjs`. Serve the repository root on port 8000, then run `python3 tests/cbse-mcq-browser.py`, `python3 tests/cbse-mcq-staff-navigation-browser.py` , `python3 tests/cbse-mcq-photos-browser.py` , `python3 tests/cbse-mcq-selection-browser.py` , `python3 tests/cbse-mcq-principal-browser.py` , `python3 tests/cbse-mcq-library-browser.py` and `python3 tests/cbse-mcq-ocr-browser.py` using Python Playwright and Chromium. Tests use synthetic data and do not establish live Firebase/Vercel deployment readiness.
